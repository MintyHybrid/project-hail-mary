Reproducing the analysis

All computationally intensive steps — NCBI retrieval, MAFFT alignment, IQ-TREE inference — are orchestrated by a targets pipeline, so nothing here depends on remembering which script to run in which order.

# Install the pipeline dependencies once
install.packages(c("targets", "tarchetypes"))
remotes::install_local("packages/potytools")

renv::restore()     # exact package versions used for the rendered book

targets::tar_make()        # runs the pipeline, skipping up-to-date steps
targets::tar_visnetwork()  # inspect the dependency graph

External tools required on PATH for a full pipeline run: mafft, iqtree2, hmmscan.

Not everything flows through the pipeline: the ELM short-linear-motif search runs via a separate gget-based path (scripts/prep_elm_regions.R → scripts/gget_elm_run.py), described in Chapter 4.

potytools

The reusable analysis functions — GenBank parsing, codon usage bias (RSCU/ENC/CAI/GC), host mono/dicot classification, motif-flank extraction, phylogenetics helpers, sequence logos — live in an installable, tested R package rather than being redefined chapter by chapter.

remotes::install_local("packages/potytools")
library(potytools)

It targets rOpenSci standards: documented with roxygen2, tested with testthat, lint-clean and R CMD check-clean, and is being prepared for peer review.

## Reproducing the analysis

All computationally intensive steps — NCBI retrieval, MAFFT alignment, IQ-TREE
inference — are orchestrated by a `targets` pipeline, so nothing here depends
on remembering which script to run in which order.

```r
# Install the pipeline dependencies once
install.packages(c("targets", "tarchetypes"))
remotes::install_local("packages/potytools")

renv::restore()     # exact package versions used for the rendered book

targets::tar_make()        # runs the pipeline, skipping up-to-date steps
targets::tar_visnetwork()  # inspect the dependency graph
```

External tools required on `PATH` for a full pipeline run: `mafft`, `iqtree2`,
`hmmscan`.

Not everything flows through the pipeline: the ELM short-linear-motif search
runs via a separate `gget`-based path
(`scripts/prep_elm_regions.R` → `scripts/gget_elm_run.py`), described in
[Chapter 4](notebooks/04_protein_motifs.qmd).
